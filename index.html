    Server-authoritative melee combat

    The client sends one thing: "I want to swing, aiming this way." It never says who it hit or for how much. The server checks the request, picks targets from its own positions, and applies damage.

    • Every remote payload is type-checked. NaN, wrong types, extra keys and metatables are dropped.
    • A token-bucket rate limiter per player. A spam script gets a few swings, then nothing.
    • Cooldowns and combo state use server time. A four-hit combo with a finisher, knockback and end lag.
    • The client's aim is trusted only within 75° of where the server sees the character facing.
    • Latency slack adds a little range for laggy players, and it is capped so it can't be abused.

    Player data with ProfileStore and migrations

    Games change their save format. Old players still have old saves. This system upgrades any saved version to the current one, step by step, when the player joins.

    • Session locking with ProfileStore, so the same data is never live on two servers. No item dupes.
    • Migrations run on a copy. If one step fails, the original save is untouched.
    • Data from a newer server version is refused, never downgraded. The player rejoins a newer server.
    • Developer products are granted exactly once: the receipt id is saved with the reward.
    • Migrations run before Reconcile. Otherwise Reconcile stamps the new version on old data and every step is skipped.

    Idle economy with offline earnings

    Six generators with exponential prices, milestone multipliers, prestige, a paid 2x boost and earnings while away. The server owns the cash. The client only shows it.

    • Buy x1, x10 or max. "Max" uses the closed form of the geometric series, so it is instant at any amount.
    • The last-online time is written right before every save. A server crash loses at most one autosave of progress.
    • A missing timestamp or a clock that went backwards earns nothing.
    • The cash counter is interpolated on the client between server updates, so it ticks smoothly.
